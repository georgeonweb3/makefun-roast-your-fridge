A deterministic program that writes a single-line roast of my fridge to `/output/entry.txt` for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty. One line, at most 200 characters, built from a specific, recognisable detail of the appliance with a twist that pays off in the last few words.

## Run it

```sh
python3 main.py
```
